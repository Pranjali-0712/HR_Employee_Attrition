# HR Employee Attrition Dashboard – Power BI


An interactive HR Employee Attrition dashboard created using **Microsoft Power BI** to analyze employee turnover and identify factors associated with employee attrition.

## Objective

The objective of this project is to create an interactive visualization that helps answer:

> **Why are employees leaving?**

The dashboard allows users to explore employee attrition based on different factors such as department, age group, job role, overtime, and gender.

## Dataset

The project uses the **IBM HR Analytics Employee Attrition & Performance** dataset.

The dataset contains employee information such as:

- Age
- Gender
- Department
- Job Role
- Job Satisfaction
- Monthly Income
- OverTime
- Years at Company
- Attrition

## Dashboard Features

The Power BI dashboard includes:

### Key Performance Indicators

- Total Employees – 1,470
- Attrition Count – 237
- Attrition Rate – 16.12%
- Average Age – 36.92

### Visualizations

- Attrition by Department
- Attrition by Age Group
- Attrition by Job Role
- Attrition by Overtime

### Interactive Filters

Users can filter the dashboard using:

- Department
- Age Group
- Gender

## Key Insights

The dashboard helps identify patterns in employee turnover.

Some important observations include:

- Attrition is higher in certain departments compared with others.
- Employees in the 25–34 age group show comparatively higher attrition.
- Some job roles have significantly higher employee turnover.
- Overtime is an important factor associated with employee attrition.
